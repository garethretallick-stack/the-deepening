# The Deepening (beta)

An endless, very dark dungeon crawler. Pick a class, go down, and see how deep you get before it eats you.

**Play in your browser:** https://garethretallick-stack.github.io/the-deepening/

This link always has the latest beta build. Keyboard and mouse or a controller.

Feedback is very welcome: what killed you, what felt unfair, what was boring, what was fun, and how deep you got.
